Irodori-TTS の声フォルダ
========================

ここに置いた WAV ファイルが、そのまま声(キャラクター)として使えます(ファイル名が声の名前)。
  例: mio.wav  →  声 "mio"

最初から入っているキャラクター
- 「女声1〜6」「男声1〜4」は、参照音声なしで生成した声(シード固定)を参照音声にしたものです。
  声の高さで分けています(女声1〜3 は高め、女声4〜6 は落ち着いた高さ)。
- 不要なら削除してかまいません(PlayEngine をビルドし直すと戻ります)。

キャラクターを作る
- 1 つ上のフォルダの「キャラクター作成.cmd」を実行すると、ブラウザで作成ページが開きます
  (サーバーが動いていれば http://127.0.0.1:8088/ を直接開いても同じです)。
- 参照音声なしでランダムな声を生成して試聴し、気に入った声に名前を付けて保存すると、
  このフォルダに「名前.wav」ができ、以後はその声で固定して話します。

その他
- 自分で用意した参照音声も置けます。1 ファイルあたり数秒〜30 秒程度、雑音の少ない 1 人の声がおすすめです。
- 複数のファイルを 1 つの声にまとめるときは voices.json を置きます。
    { "mio": { "ref_wavs": ["mio_01.wav", "mio_02.wav"] } }
- Speaker Inversion の埋め込み (*.speaker.safetensors) も置けます。
- 声 "none"(PlayEngine の一覧では「ランダム」)は参照音声なしで、話すたびに違う声になります。

サーバーの起動中に追加したファイルもすぐ使えます。
